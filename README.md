📝 Flask User Management API
A simple RESTful API built with Python Flask to manage user data.
This API demonstrates CRUD operations (Create, Read, Update, Delete) and is perfect for learning how REST APIs work.



🚀 Features
✅ Create new users

✅ Retrieve all users

✅ Retrieve a single user by ID

✅ Update existing users

✅ Delete users

✅ Handles invalid requests and missing users

✅ Prevents /favicon.ico 404 errors in the browser



🛠 Technologies Used
-Python 3.x

-Flask

-JSON for data transfer



💡 Notes
Users are stored in a Python dictionary, so data is temporary. Restarting the server clears all users.

user_id is auto-incremented starting from 1.

/favicon.ico route prevents browser 404 logs.


In short i have made this REST API AND performed CRUD operation's (POST, GET, PUT, DELETE) in postman API using the link of localhost etc it 
was a great learning project about Flask and concepts of python.
